# Step memos

Each step ends with a plain-language memo. The memo is saved to the claude.ai project as `claude/memos/step-NN-<name>.md`, with a copy here.

Sections:

1. In one paragraph
2. What was built
3. Decisions: decision, options considered, choice, and why
4. Results: key numbers, with figures in `reports/figures/`
5. What it means for the model
6. Questions for Benjamin (the checkpoint)
7. Next step
